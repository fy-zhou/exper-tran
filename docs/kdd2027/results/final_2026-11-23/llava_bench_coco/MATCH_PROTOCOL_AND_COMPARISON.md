# LLaVA-Bench (COCO) 匹配率协议与解释

## 当前测量

1. 数据固定为官方 30 图、90 题。每张图各有一题对话、详细描述、复杂推理。Ours 在 Gemma 31B、InternVL 14B、Qwen 27B 上分别有 90 对冻结的 clean/adv 回答。
2. 每张原图对应实验前固定的一张目标参考图。评分读取目标 ID、PNG 哈希和该图的 COCO 人工 captions。目标 ID 在评分前已经固定。全部 90 道题仍是原图的官方问题。
3. 匹配裁判收到原问题、目标图的人工描述和一条候选回答。它看不到 clean/adv 标签和攻击方法，亦不直接看目标 PNG。GPT-6 Luna medium 通过已登录的 Codex CLI 在独立会话中给 True/False。
4. True 要求回答至少部分解决原问题，并包含目标描述支持的具体信息。泛泛的回答、无关猜测和单纯否定不算命中。该规则允许语义同义，字段中没有逐字匹配条件。
5. 按每个模型分别报告 clean 与 adv 命中数。全量分母为 90，每题型分母为 30。未完成或解析失败的判定单列。质量降分走独立请求，使用原图官方参考答案、官方视觉上下文与评分规则，分别计算相对分后相减。裁判替换为 GPT-6 Luna medium。

## 与论文的区别

[公开论文 §5.2、表 6](https://arxiv.org/pdf/2505.01050#page=14) 从目标图对应的原题及标准答案出发，把另一张图拿来作为扰动输入。它用 GPT-4o 评目标参考答案的部分符合。两套协议在目标出题方向、参考证据、判定细则和裁判上均不同，被评估模型也不同。

表 6 的公开区间依次是对话 26.7%–57.8%、详细描述 11.1%–34.4%、复杂推理 27.7%–96.7%。这些数值作为论文参照。按用户最新要求，baseline 只评质量降分，Ours 匹配结果完整保留。公开区间不能用于直接排名或显著性推断。

## 降分大而匹配少时怎么解释

- **配对和可回答性**。原图 20650 的对话题问橙色盘子上有哪些食物，其固定目标 170099 的人工描述说的是穿衬衫打领带的人和沙发。这道题的目标证据不支持给出题目要求的食物清单。
- **视觉证据与裁判约束**。目标 captions 通常概括场景，可能省略推理需要的关系。即便回答合理地否定原图题目的前提，纯否定也会判 False。
- **迁移效果**。原图答案质量下降也可能表现为泛化、拒答或无关内容。只有出现目标特有语义才支持定向迁移。按题型对照 clean/adv 命中和质量分，并回查原始回答，以区分这两种现象。
- **结论边界**。当前没有真正目标图在原题下的同裁判对照，因此可回答性、标注覆盖及实际迁移不足各占多少尚未确定。不能从低匹配率单独归因给优化器。

baseline 阶段复用同一批问题、经过校验的冻结回答、相同目标模型和同一裁判。FOA、M-Attack、PGD、MI-FGSM 均为此套 LLaVA 的 50 步版本。分析按目标与题型拆开，先核对 clean 分、adv 分、降幅、实际完成分母，再结合每个方法的冻结配置与逐题输出讨论差异。

## 补充实验结果与下一阶段方法问题

固定六图的裁判复核显示，严格规则下 clean 0/18、adv 3/18；部分符合规则下 clean 0/18、adv 4/18。另用论文式目标图出题的小试，在 Gemma 31B 的两张目标图六道题上，得到干净源图 0/6、扰动源图 0/6、真实目标图 5/6。真实目标图唯一未命中是把参考答案中的鸭叫成了鹅。两次小试使用不同问题或样本，不能作直接的逐题前后比较。

当前方法的主要开放问题是能否把目标对象的颜色、空间位置和对象关系定向传给目标模型。现有实验发现属性错位及场景错配，但尚未单独量化位置与关系。后续重点区分 48 图参考邻域、全局池化和跨模型迁移的影响。这一限制不改变已报告的原问答质量降分，也不把质量下降解释为精确的目标语义命中。完整后续设计见仓库的 `docs/kdd2027/LLAVA_FINE_GRAINED_TRANSFER_PLAN.md`。
