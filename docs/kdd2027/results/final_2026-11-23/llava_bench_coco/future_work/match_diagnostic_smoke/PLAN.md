# 六图匹配诊断

先完成当前 LLaVA 30 图评分。诊断单独输出，不改正式评分和 baseline。固定六张官方原图及其既有冻结目标，先测 Gemma 31B。抽样仅读官方清单，未读取任何入选图的模型回答或判定。

每图在原图、冻结扰动图、真实目标图三种输入上使用同样问题。先测原图的三条官方题，再测一条可用于任意图片的共享描述题。总计 72 条回答，原图和扰动图的 36 条旧回答经身份校验后复用，需新增推理 36 条。真实目标图是正对照，用于估计协议可测上限。共享描述题检查源图特定题目是否压低匹配率。

同一批回答分别用现有严格规则和论文式部分符合规则盲评。两种规则都记录 clean 命中、adv 命中和真实目标图命中，注明题型与分母。对于无法由目标图回答的原题，记录不适用原因并保留其在正式原题结果中，不通过删分母抬高结果。宽规则如同时抬高 clean 和 adv，报告净增益而非单看 adv。先复核真实目标图的表现，再解释迁移率，六图诊断只作探索。

若真实目标图在共享问题下仍低，先审查目标证据和裁判规则。若原题低而共享题高，优先调整后续定向评估的题目构造。若真实目标图高且 adv 仍接近 clean，当前冻结图像缺乏目标转移证据，再考虑另做算法探索。该协议仍与论文的目标图专属问答不同。

运行前核对 A100 实际显存和所有权。评分只用订阅 Codex CLI 的 GPT-6 Luna medium，正式基线继续只评质量。
